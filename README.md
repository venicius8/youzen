# YouZen

**Um app de bem-estar e meditação construído com Next.js**  
Práticas guiadas de respiração, paisagens sonoras relaxantes, frases motivacionais, diário de gratidão e muito mais — tudo para ajudar você a encontrar paz no dia a dia.

## 🚀 Demo

[Acesse a demo ao vivo](https://youzen.vercel.app)

## ✨ Principais Funcionalidades

- 💬 **Phrases** – Leitura de frase positivas e motivacionais
- 🫁 **Breathing** – Exercícios de respiração guiada por um círculo
- 🎧 **Soundscape** – Combinações de sons naturais e relaxantes
- 📝 **Gratitude** – Diário de agradecimento
- 👤 **Perfil do Usuário** – Estatítica do usuário e tempo de tela do usuário
- 📱 **Design Responsivo** – Perfeito para desktop e mobile
- 🔍 **Explorar Técnicas** – Descubra novas práticas de mindfulness

## 🚀 Começando Localmente

Certifique-se de ter **Node.js ≥ 18** instalado.

```bash
git clone https://github.com/venicius8/youzen.git
cd youzen
npm install
npm run dev
```

📦 Scripts Úteis

| Script        | Descrição                            |
| ------------- | ------------------------------------ |
| npm run dev   | Inicia o servidor de desenvolvimento |
| npm run build | Gera build de produção               |
| npm run start | Inicia em modo produção              |
| npm run lint  | Verifica código com ESLint           |

🏗️ Estrutura do Projeto

```
app/
├── components/          # Componentes reutilizáveis (Header, UI, etc.)
├── ... funcionalidades  # Várias pastas do projeto (Breathing, Phrases, etc.)
├── explore/             # Exploração de técnicas
├── profile/             # Perfil e resumo do usuário
├── about/               # Sobre o projeto
├── page.tsx             # Página inicial do app
public/                  # Imagens e assets estáticos
utils/                   # Utilitários (timeTracker, dados)
```
